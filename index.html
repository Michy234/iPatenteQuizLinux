iPatenteQuizLinux

iPatente Quiz for Linux

An installer for running the Windows/UWP build of iPatente Quiz on Linux with Wine. It starts from an .msixbundle you have already obtained: the script never downloads the application package itself.

What it does

  • Extracts the correct APPX payload from an MSIX/AppX bundle.
  • Unpacks app/resources/app.asar, which is needed for the application to run correctly in Wine.
  • Creates a dedicated Wine prefix and application-menu launcher.
  • Registers the iPatente Quiz icon with the desktop environment.
  • Installs Framework7, Material Icons, Microsoft Core Fonts, and Noto Color Emoji into the WINEPREFIX, so as not to break the app (you can disable font installation with --no-fonts).

Requirements

Required commands are wine, 7z, unzip, and asar. The script checks for them before changing anything. It detects common Debian/Ubuntu, Fedora/RHEL, Arch/Manjaro, and openSUSE systems and suggests an installation command.

curl and winetricks are recommended. They install extra icon, text, and emoji fonts in the isolated Wine prefix. Font downloads are optional and can be disabled with --no-fonts. The installer uses a small spinner with elapsed time for longer setup steps. During font downloads, curl shows the transfer percentage, elapsed time, and estimated time remaining.

Install

Make the script executable and give it your .msixbundle:

chmod +x install.sh
./install.sh /path/to/iPatenteQuiz.msixbundle

You can also run ./install.sh by itself; it will ask for the bundle’s path.

To also create a Desktop launcher:

./install.sh --desktop /path/to/iPatenteQuiz.msixbundle

By default, the application is installed to ~/.local/share/iPatenteQuiz and uses the isolated prefix ~/.wine-ipatente-quiz. Reinstalling preserves the previous application directory as a timestamped backup.

Launch

Open iPatente Quiz from the application menu, or run:

ipatente-quiz

Options

--desktop              also create a launcher on the desktop
--no-fonts             skip downloaded and supplementary fonts
--verbose              show detailed extraction and font setup output
--app-dir DIRECTORY    custom application directory
--wineprefix DIRECTORY custom Wine prefix directory
--uninstall            remove the app, prefix, launchers, icon, and backups

For all options, run ./install.sh --help.

Uninstall

./install.sh --uninstall

If a custom application directory or Wine prefix was used, provide the same values to the uninstall command:

./install.sh --uninstall \
  --app-dir /custom/path/iPatenteQuiz \
  --wineprefix /custom/path/wine-ipatente-quiz
